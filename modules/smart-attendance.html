VOIDNEXUS Module

Smart Attendance

Automated attendance tracking integrated with campus identity systems.

Description

Smart Attendance is VOIDNEXUS’s attendance module, built on top of ProxNet identity. It records check-in/check-out automatically using presence and verification, so faculty don’t need to run manual rolls and students can’t proxy. Data flows into the admin dashboard and can be exported or synced to your existing academic systems.

Features

  • → Automatic attendance from ProxNet presence and verification
  • → Per-class and per-session tracking
  • → Real-time dashboards for faculty and admins
  • → Export and API for ERP/LMS integration
  • → Fraud-resistant, audit-ready records

Use Cases

Lecture & lab attendance

Automated roll for every class without manual sign-in sheets.

Compliance & reporting

Audit trails and reports for accreditation and administration.

Parent & guardian visibility

Optional visibility into attendance for authorized contacts.

Multi-site campuses

One system across buildings and departments.

Integration

Smart Attendance uses ProxNet for identity and presence; deploy both for full automation, or integrate attendance data via API with your existing identity source. We can sync with college ERPs and LMSs so attendance appears where your faculty already work.
