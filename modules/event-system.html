VOIDNEXUS Module

Events System

Create and manage campus events and student participation.

Description

The Events module lets campuses create, publish, and manage events—from workshops and seminars to fests and hackathons. Students discover events in the VOIDNEXUS app, register or RSVP, and get reminders. Organizers get a dashboard for capacity, check-in, and follow-up. Supports both single-campus and inter-college events so other institutions’ students can discover and join.

Features

  • → Event creation with date, venue, capacity, and description
  • → Registration / RSVP and waitlists
  • → Check-in and attendance for events
  • → Inter-college events: host and discover across campuses
  • → Notifications and reminders

Use Cases

Campus events

Workshops, seminars, fests, and club activities.

Inter-college events

Host events that students from other colleges can discover and join.

Live sessions

Webinars and live streams with registration.

Participation tracking

Check-in and proof of participation for certificates or credit.

Inter-College Events

Colleges can mark events as open to other campuses. Those events appear in a shared discovery feed so students from partner or connected institutions can see and register. Identity remains per-institution; participation and check-in are tracked so hosts know who attended. Builds a network of campus events without separate platforms.

Integration

Events use VOIDNEXUS identity and roles. They can be promoted via the Announcements module and discussed in Campus Messaging. Event attendance can be exported or used for participation records. Inter-college discovery requires VOIDNEXUS to be deployed across participating institutions with federation enabled.
