Cloud Hosted Deployment

The system is hosted on cloud infrastructure managed by OBSCURON VOID LABS or your preferred cloud provider. Updates, backups, and scaling are handled in the cloud, reducing the need for on-site IT capacity. Suitable for institutions that want minimal infrastructure footprint and predictable operational overhead.

On-Premise Deployment

The system is deployed within the institution’s own data center or server room. All data and processing remain on your infrastructure, giving full control over location and access. Ideal for institutions with strict data-residency or security policies that require systems to run entirely on-premise.

Hybrid Deployment

A combination of on-premise and cloud components: for example, identity and gateway on-premise with analytics or backup in the cloud. Allows institutions to keep sensitive workloads on-site while using cloud services for scalability or disaster recovery. Deployment topology can be tailored during implementation.
